# 成长种子：公式、代码和回测（2026-11-05）

## 文件

| 文件 | 内容 |
|---|---|
| `fe_growth.py` | 公式本体：乱数（xorshift128）、种子前进、一次升级（含重抽和保底）、成长率、往后推演 |
| `solve.py` | 反推种子（numpy 向量化，暴力试 0～2³¹−1） |
| `demo.py` | 用反推出的种子回测观星记录，并往后推演 5 级、比较几个职业 |

## 公式（来自 fireemblem.top/growth-seed 的 JS，作者 Pser_hanser）

1. 每个角色存一个 31 位种子。每升 1 级或每考 1 次试，种子前进一步：`新种子 = Xorshift128(旧种子).next() & 0x7fffffff`。换职业不动种子。
2. 一级的加点：用当前种子初始化 Xorshift128，按 **HP 力 魔 技 速 幸 防 魔防 魅** 的内部顺序，对成长率余数 r>0 的每项抽一个数 `U = (x & 0x7fffffff) % 1000000`，`U < r × 10000` 就加 1；成长率的整百部分必涨。
3. 涨的项数 < 保底（第一、二部 2，第三部起 0）就整轮重抽，最多再抽 3 次；还不够就从没涨的项里按成长率加权补 +1。
4. 成长率 = 个人 + 职业修正 + 坐骑 × 倍率 + 之道 + 技能，负数压到 0。

验证到的规律：
- **考试确实推进一步种子**：法毕欧的 3 次考试、杨界和米迦的考试，前后都对得上。
- **换职业只换成长率**：米迦考士兵后的两级用士兵成长率算，回到斗士后用斗士算，全对。
- 对不上的都只差 1 项，其他 8 项全对。看了那一项的乱数，离成长率的线差 6～22 个百分点，不是压线。所以要么是记录时点错了，要么那一刻有一项成长率差了这么多。

## 成长路线规划（11-05 晚）

- `weights.json`：能力权重（与主表「能力权重」tab 同步）。
- `planner.py`：动态规划。每一步种子可以「用某个已有职业升级」（随时换，包括转回低级职业）或「考试」（吃掉一步；考新职业的话假定考过、之后可用，例如土匪、恶棍）。在考试次数上限内求 Σ权重×加点 最大；多考一次至少多 8 分才建议。
- `run_plans.py`：命令行，`python3 run_plans.py 迪托利希 --to 35 --max-exams 4`。改 `OWNED`（已有职业）和 `EXAM_OPTIONS`（可考职业）。
- `make_sheet.py`：生成主表「种子」「成长路线」两个 tab 的内容。
- 没考虑：考试通过率（默认都过）、职业能力补正和最低能力、武器技能等级要求、第二部自动补到 Lv35 时怎么用种子。
