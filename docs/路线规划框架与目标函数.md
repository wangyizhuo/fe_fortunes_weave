# 火焰纹章：万紫千红 · 以终为始的路线规划框架与统一目标函数

> 本文档将过去所有 case-by-case 决策（PR #1–#27、`levelup/rng/decisions.json`、`config/route_config.json`）统一收拢为一套**目标明确、以终为始**的数学目标函数、Good/Bad 判据与两阶段规划算法，并在 [`modules/route/objective.py`](../modules/route/objective.py) 与 [`modules/route/two_stage_planner.py`](../modules/route/two_stage_planner.py) 中落地。

## 1. 为什么要重构：旧规划器的根本症结「坏乱数幻觉」

旧规划器（`levelup/rng/planner.py`）对非 P0 角色采用 `_first_bad_timing`（PR #26）：**在「当前已有职业」下找第一个坏乱数，把考试塞进去**。这套局部规则曾通过不断加补丁（`EXAM_AT_OVERRIDE`、`NO_SKIP_SEEDS`、`TRAIN_CASE`、`first_bad_exam` 等）来贴合人工判断，但存在根本盲区：

> **坏乱数幻觉（Myopic Bad-Seed Illusion）**：某个种子在**旧职业**（如飞鸵兵、诅咒师）下只有 7–9 点看起来是坏乱数，但在**转职后的新职业**（如重装步兵、牧师）下却可能是 **5 项全跳 / 16 点的大好乱数**。只看旧职业把考试放到这个种子上，等于亲手把新职业最肥的一颗种子吃掉了。

典型反例：
- **努蒂奴（P2）**：旧算法见第 7 步（Lv21）在飞鸵兵下偏差，把「重装步兵」考试放到了 Lv21；但如果在 **Lv18（第 4 步）** 提前转职，第 7 步在重装步兵下变成高成长好乱数，**同花 500G、同练 2 段，净赚 +2 总点数、+6 加权分（含 +3 保底）、+2 级重装精通**。
- **乌尔坦德（P2）**：旧算法见第 9 步（Lv23）在诅咒师下偏差，拖到 Lv23 才考「牧师」；如果在 **Lv19（第 5 步）** 提前转职，第 9 步在牧师下变成大好乱数，**同花 500G、同练 1 段，净赚 +4 总点数、+13 加权分、+3 级牧师精通**。

## 2. 核心洞见：区间不变性定理（Interval Invariance Theorem）

> **Yizhuo 的核心洞见**：比较「在 $t_1$（如 16/18 级）转重装」和「在 $t_2$（如 21/22 级）转重装」，在 $t_2$ 之后，两条路线消耗的乱数数量、所处等级、以及已有职业集合**完全一致**，因此 $t_2$ 之后的所有成长都会抵消。

### 精确四项归因公式（早考 $t_1$ 减晚考 $t_2$，$t_1 < t_2$）

在固定总乱数窗口 $N$ 与固定职业集合 $T$ 下，把「早考方案 $\pi_{\text{early}}$」减「晚考方案 $\pi_{\text{late}}$」，总差异严格分解为四项（见 [`compare_timing_interval`](../modules/route/two_stage_planner.py)）：

$$\Delta(\pi_{\text{early}} - \pi_{\text{late}}) = \underbrace{\big(g_{\text{new}}(t_2) - g_{\text{old}}(t_1)\big)}_{\text{① 乱数置换差}} + \underbrace{\sum_{k=t_1+1}^{t_2-1}\big(g_{\text{with }c}(k) - g_{\text{without }c}(k)\big)}_{\text{② 区间 }(t_1,t_2)\text{ 职业加成差}} + \underbrace{\Delta\text{Floor}(t_1, t_2)}_{\text{③ 保底差}} + \underbrace{\Delta\text{Carry}(>t_2)}_{\text{④ 区间外残差（通常为 0）}}$$

再加上两项工程代价/收益：
- **⑤ 职业精通差** $\Delta M = M_{\text{early}} - M_{\text{late}}$（早转多用目标职业升级的级数，更快拿精通特技）
- **⑥ 金币与风险差** $\Delta G$（早考是否额外触发后续纯跳过）、$\text{margin}(t_1) = \text{pct}(t_1) - \text{roll}(t_1)$（公式估计成功率是否压在 3% 拟合误差线内）

实测验证：对努蒂奴、乌尔坦德、杨界、米迦艾拉全部 6 组早晚对比，**第 ④ 项区间外残差全部严格等于 `0 点 / 0 分`**，完整印证区间不变性定理。

## 3. 以终为始的统一目标函数 $J(\pi)$

在固定乱数预算 $N = \max(\text{目标等级}, \text{当前等级}+15) - \text{当前等级} + 1$（所有候选路线消费**完全相同数量**的乱数，杜绝靠多吃种子虚增总分）内，对任意满足硬约束的路线 $\pi$，统一最大化：

$$J(\pi) = \underbrace{W_{\text{stat}}(\pi) + W_{\text{phys}}(\pi) + W_{\text{floor}}(\pi)}_{\text{纯能力加权分 } S_{\text{pure}}(\pi)} - \underbrace{\frac{G(\pi)}{g_p}}_{\text{金币折算}} - \underbrace{c_{\text{train}}(p)\cdot R_{\text{train}}(\pi)}_{\text{训练折算}} + \underbrace{\lambda_{\text{mastery}}(p)\cdot M_{\text{target}}(\pi)}_{\text{职业精通激励}}$$

其中所有分项在 [`ObjectiveBreakdown`](../modules/route/objective.py) 中独立保留、分开汇报：
1. **能力加权分** $W_{\text{stat}}$：按角色专属 9 维权重（`weights.json`）+ 均衡权重调节（防单科掉队）。
2. **体格阈值加分** $W_{\text{phys}}$：力量每跨过 5 的倍数补 +3（对应体格 +1 / 攻速阈值）。
3. **转职保底加权分** $W_{\text{floor}}$：转职瞬间将裸属性抬至职业最低保障线的真实增量。
4. **金币成本** $G(\pi) / g_p$：初级手形 300G、中级手形 500G、上级手形 3000G，按角色档位 $g_p$ 折算。
5. **考前训练成本** $c_{\text{train}}(p) \cdot R_{\text{train}}(\pi)$：需要练技能段数的惩罚。
6. **职业精通激励** $\lambda_{\text{mastery}}(p) \cdot M_{\text{target}}(\pi)$：每多 1 级用目标职业升级给微弱正向 tie-breaker（P0 `0.25`/级、P1 `0.20`/级、P2 `0.15`/级），使**同等能力下自然偏好早转职拿精通**，而不会为了精通牺牲核心属性。

### 五条硬约束（不满足直接淘汰）

| 约束 | 含义 | 对应历史决策 |
|---|---|---|
| **H1. 严格通过与安全余量** | 实测读数或 100% 满概率须 `roll < pct`；公式估计（`<100%`）须满足 `pct - roll ≥ 3%`（避开公式拟合误差） | `exam_ok` 单一口径 + 努蒂奴 Lv16 压线教训 |
| **H2. 保留种子禁踩** | `no_skip_seeds` 中人工锁定的高价值种子禁止考试或跳过 | 伊欧 Lv23 保留速/技/魔防种子（PR #24） |
| **H3. 必考 + 中级达标** | 必考职业 `required` 全部考到；尚无中级职业的角色至少考 1 个中级职业 | 迪托利希必考恶棍、艾丝双必考、P1/P2 中级兜底 |
| **H4. 考完必须用上** | 所有目标职业（`skip_take` 除外）考完后窗口内至少用来升级 ≥ 1 次，禁止拖到末步拿 0 级精通 | 防止法毕欧将必考「萨满巫师」推到第 16 步空考 |
| **H5. 简洁性门槛** | 非必考额外职业必须比「少考该职业」的子方案净增 $J \ge 2.0$，否则不考 | 避免为了 +0.5 分多花钱多折腾（`MIN_EXAM_GAIN=2.0`） |

## 5. Good vs Bad 明确定义与真实正反案例

[`classify_timing_choice`](../modules/route/objective.py) 将任意「早考 $t_1$ vs 晚考 $t_2$」划分为四类：

1. **`GOOD_EARLY`（好早转）**：稳过（100%/实测/估计余量 ≥ 3%），且早转在加权分、总点数、金币上均不劣（$\Delta W \ge 0, \Delta\text{pts} \ge 0, \Delta G \le 0$），同时多赚目标职业精通。
2. **`RISKY_EARLY`（高危假好早转 — Bad）**：账面早转更高，但公式估计成功率余量 `< 3%`，落在拟合误差带内，实机大概率考试失败、直接打乱整条乱数链。
3. **`GOOD_LATE`（好晚转 — 反之硬早转是 Bad）**：早转会吃掉关键好乱数（$\Delta W \le -3$），或导致后续不得不额外花 300G 纯跳过（$\Delta G > 0$ 且成长收益微弱）。应晚转，把「转职考试」和「吃坏乱数跳过」合二为一。
4. **`TRADE_OFF`（真实权衡）**：能力与金币/精通一正一负，按本档 `TierPolicy` 的 $J(\pi)$ 自动裁决或交人工拍板。

## 6. 两阶段算法与代码结构

算法实现位于 [`modules/route/objective.py`](../modules/route/objective.py) 与 [`modules/route/two_stage_planner.py`](../modules/route/two_stage_planner.py)：

```text
Stage 1（选职业集合 T）:
  输入: owned, required, exam_options, policy
  1. 对每个单职业 c 预计算窗口内各步目标值排名（step_hints）
  2. 枚举 0 / 1 个额外职业（全量）；P0 允许 2 个额外职业时对单职业 Top-6 做两两组合
  3. 对每个满足中级达标（H3）的职业集合 T，调用 Stage 2 求全局最优时机
  4. 按统一目标值 J(π) 排序，并执行简洁性剪枝（H5: ΔJ >= min_class_gain）

Stage 2（固定 T，找全局最优考试时机与跳过）:
  - 单职业: O(N) 严格穷举窗口内所有合法步（满足 H1/H2/H4）
  - 多职业: 用单职业 Top-6 候选步做笛卡尔积求初解 → 逐职业全窗口坐标上升直至收敛
  - 输出: 最优 EvaluatedPlan + 每场考试相对其他时机的 TimingIntervalDiff 四项拆解表
```

性能：全部 9 位角色完整两阶段规划总耗时约 **15–18 秒**（零全局状态副作用，纯函数可单测）。
