## 评级标准

1. 特效：对特定兵种/种族有效或具备特效，尤其能有效打击第三部大量出现的“冥府加护”敌人。
2. 咒宝：妖枪温德塔、邪斧维罗海特等咒宝系武器攻击“冥府加护”敌人时有概率触发“冥咒相抵”，该次伤害变 0，一律低评价。
3. 三围：威力、命中、回避越高越好（战技受耐久限制，普攻稳定高伤更重要）。
4. 射程：剑、手甲等近战武器能远程攻击加分（如雷电剑 1-2）。
5. 战技：能贯穿“冥府加护”、射程长、或攻击同时回复 HP 的战技加分。

## 逐件说明

### SS 级

**净化剑+3**（清めの剣，剑）
- 特效：追击时，给予的伤害变为1.2倍。
- 说明：受神圣祝福净化过的剑。战斗时，使敌人的“冥府加护”无效。
- 评价：战斗时可无效化敌人的“冥府加护”；命中与重量处于高水准。

**雷电剑+3**（サンダーソード，剑）
- 特效：追击时，给予的伤害变为1.2倍；雷系所造成的伤害变为2倍，炎系所造成的伤害减半。
- 说明：寄宿着雷之精灵力量的魔法剑。视为魔法攻击。可使用战技“雷击”。
- 评价：射程1-2且为魔法攻击，便于处理物防高的敌人；雨天时可打出超高火力。

**查尔摩克西斯+3**（ザルモクシス，斧）
- 特效：至少给予5伤害。
- 说明：据说蕴藏甚至能劈开天空之力的斧。可使用战技“霸绝+”。
- 评价：战技“霸绝+”可无效化“冥府加护”，且威力极高；威力、命中处于高水准。

**史米尔诺斯之雷甲+3**（スミルノスの雷甲，手甲）
- 特效：战斗时，若敌人未装备手甲，回避+15。
- 说明：寄宿着雷之力的至高之圣刻。可使用战技“雷甲托隆”。
- 评价：战技“雷甲托隆”为魔法攻击且射程1-2；重量仅为1，容易与其他装备搭配。

**索雷尔之辉枪+5**（ソレルの輝槍，枪）

- 说明：寄宿着太阳力量的至高之圣刻。可使用战技“太阳”。
- 评价：锻至最大后，战技“太阳”可按造成的伤害回复HP；威力、命中、重量均处于高水准。

**卡拉之弓+3**（カーラの弓，弓）
- 特效：说明：“天风”的命中+20。
- 说明：寄宿着风之力的至高之圣刻。可使用战技“天风”。
- 评价：战技“天风”射程3-10，可进行超远距离攻击；蕾达篇第10章起即可使用。
